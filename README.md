# Backgammon K.o.-Turnier

Eine einzelne Seite für ein K.o.-Turnier mit 2–10 Spielern. Kein Build: `index.html` im Root ist die ganze App und läuft direkt auf GitHub Pages.

Namen eintragen, die Setzliste auslosen, den Sieger antippen. Freilose, Folgerunden und die Siegerehrung bleiben im Browser gespeichert.

## Lokal öffnen

`index.html` im Browser öffnen, oder:

```bash
python3 -m http.server 8080
```

## GitHub Pages

Repository → Settings → Pages → Branch `main` → Ordner `/ (root)`.
